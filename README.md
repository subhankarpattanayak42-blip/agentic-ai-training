# Agentic AI Training — Military Professionals

Interactive HTML slide deck for the two-day hands-on workshop at IMI Bhubaneswar.
Navigate with arrow keys / space, click anywhere, or use the dot rail on the right.

**Presented by Subhankar Pattanayak**

## Presentation Controls
- `→` / `↓` / `Space` / `Enter` — next slide
- `←` / `↑` / `PageUp` — previous slide
- `Home` / `End` — jump to first / last slide
- Click anywhere (or the dot rail) to navigate

## Structure
1. Title
2. Day 1 — Foundations & Live Demos
3. LLMs vs Agents · Key Criteria · Timeline · Types · Live Demo
4. Day 2 — Technical Deep Dive & Infrastructure
5. Deployment · Build vs Buy · Custom Harnesses · OpenRouter
6. Capabilities · Use Cases · Suggested Pacing
7. Thank You
