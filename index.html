Foundations

LLMs vs Agents

LLM (Large Language Model)

  • Responds to prompts
  • Text in, text out
  • No memory between sessions
  • Cannot take actions
  • Examples: GPT-4, Claude, Gemini

Agent (AI Agent)

  • Autonomous goal-seeking
  • Memory & context-aware
  • Uses tools & takes actions
  • Multi-step reasoning
  • Examples: Grokbot, OpenClaw, AutoGPT
An Agent = LLM + Memory + Tools + Autonomy

Day 2 · Custom Build

Building Custom Agents

OpenClaw Harness

The open-source self-hosted standard.
  • Open-source framework
  • Multi-model support (GPT, Claude, Gemini)
  • Plugin architecture
  • WhatsApp, Telegram, Discord integration
  • Self-hosted — full data control

DeepSeek Harness

Cost-efficient alternative for constrained setups.
  • Cost-effective inference
  • High-quality reasoning
  • Open-source models
  • OpenAI-compatible API
  • Strong coding & analysis; resource-constrained friendly
